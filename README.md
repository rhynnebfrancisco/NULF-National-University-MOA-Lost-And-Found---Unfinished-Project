# NULF: National University Lost & Found

**National University Lost & Found (NULF)** is a Java-based lost and found management system developed for use within the **National University – Mall of Asia (NU MOA) campus**.

The system is designed to provide a centralized platform for managing lost and found items within the university. It helps organize the process of reporting lost items, recording found items, and managing information related to item recovery.

## About the Project

Lost and found concerns within a campus can become difficult to manage when reports are handled manually or information is scattered across different channels. NULF was developed to provide a more organized digital system specifically for the NU MOA campus community.

The project was developed using **Java** as part of an academic programming project.

## Project Scope

NULF is intended specifically for **lost and found management within the NU MOA campus**. It is not designed as a public or nationwide lost-and-found platform.

## Technology

* **Programming Language:** Java
* **Project Type:** Desktop / Java Application
* **Application:** Campus Lost and Found Management System

## Purpose

The main purpose of NULF is to make the management of lost and found items within NU MOA more organized and accessible through a computerized system.

## Status

This repository contains the Java implementation of the **National University Lost & Found (NULF)** system developed for academic purposes.
